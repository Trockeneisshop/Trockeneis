## Technische Anwendungen: CO₂-Schneestrahlen und Trockeneisstrahlen

Neben der Kühlung wird festes Kohlendioxid auch für industrielle Reinigungsverfahren eingesetzt.

Beim **CO₂-Schneestrahlen** und **Trockeneisstrahlen** werden Verschmutzungen trocken, materialschonend und ohne Wasser oder aggressive Reinigungsmittel entfernt.
